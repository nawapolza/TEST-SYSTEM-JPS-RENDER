# JPS Calm Contrast UX/UI release

- Replaced blue-gradient hero panels with soft white/blue panels so dark-blue headings remain legible.
- Standardized primary buttons to solid JPS blue with white labels.
- Softened background surfaces, borders, shadows and inactive tabs for lower visual fatigue.
- Improved mobile user-management spacing and tab layout.
- Added a final CSS layer after the existing theme stack to override conflicting legacy page styles.

Build command: `cd frontend && npm install && npm run build`
